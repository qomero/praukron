- Dashboard force view: Work gains a second view beside the lanes, the
  **force view**, for analysing relations. Tasks are clustered by module, each
  cluster a named circle, and a decision or assumption shared across modules
  sits between them. It draws the same nodes, lines, selection, filters and
  side panel as the lanes, with the same shapes and words. `2` opens it and
  `1` returns to the lanes; the chosen view is remembered. The layout is
  computed in the page only when the view first opens, seeded so the same
  input gives the same positions; it settles by itself, and with reduced
  motion it is drawn once at rest. The page now opens on Work on a first
  visit; an address fragment or the last workspace still wins.
