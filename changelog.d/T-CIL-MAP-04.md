  Symbols columns counting each task's current references, `Files:` and `Symbols:` anchors
  included, and its search also finds tasks by an exact or partial path or a symbol name. Each
  task record in Audit, and the task dialog that shows it, has a Code References section:
  planned and observed files and symbols with relation, authorization, verification, revision,
  provenance and up to three other tasks that reference the same artifact; unresolved, stale,
  replaced and withdrawn references are marked, not hidden. A new Code artifacts group in Audit
  gives each file or symbol its current path, earlier paths (`Was`), referencing tasks and their
  decisions, opened in the dialog from a reference. Every label is in English and Vietnamese, and
  the page reads without JavaScript (T-CIL-MAP-04).
