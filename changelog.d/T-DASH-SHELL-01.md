- Dashboard shell: the page is one shell around Home, Work, Review and Audit,
  with a header and search, a **Waiting for you** strip, a side panel and a
  bottom panel that share one project, one selection and one set of filters.
  Work opens on the **lanes** view: phases as columns, modules as bands, a
  task's dependency depth from left to right, decisions and assumptions below
  the tasks they bear on, positions computed in Python. The waiting model lists
  open owner tasks, DONE owner tasks without the owner's verification and open
  assumptions, each once, split into *now* and *upcoming*, with what each blocks
  (transitive first, direct beside it) or affects, and dates only from records;
  kinds the project does not record are named, not counted as zero. Each panel
  hides, shows and resizes, and `f` hides them all; keys `s`, `b`, `Shift+W`,
  `f`, `1`, `/`, arrows, Enter and Escape work without a pointer, and a text
  view and a relations list carry the graph as words. The page stays a derived
  view: it writes nothing new.
